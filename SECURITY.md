# Security Policy

## Supported Versions

This project has no tagged releases. Only the latest commit on the `main`
branch is supported; fixes land there.

## Reporting a Vulnerability

Open a private security advisory through the repository platform or contact
the maintainers privately. Do not open a public issue for security
vulnerabilities.

Upstream vulnerabilities (LiteLLM, Codex, Azure AI Foundry) should be
reported to their respective maintainers.

## Non-affiliation

This project is not affiliated with, endorsed by, or officially supported by
Microsoft, Azure, OpenAI, Anthropic, DeepSeek, xAI, LiteLLM (BerriAI), or Moonshot AI.
